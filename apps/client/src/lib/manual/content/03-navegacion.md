La interfaz tiene dos niveles de navegación: el **encabezado global**, siempre visible, y el **panel de Administración**, que agrupa las herramientas de gestión.

## Encabezado global

En la franja superior encontrarás el logo de la Facultad y los accesos principales:

| Acceso             | Qué muestra                                               |
| ------------------ | --------------------------------------------------------- |
| **Publicaciones**  | Catálogo de publicaciones científicas                     |
| **Estadísticas**   | Indicadores de la facultad, departamentos y líneas        |
| **Académicos**     | Listado de académicos (público o interno según la sesión) |
| **Administración** | Panel de gestión (solo con sesión iniciada)               |
| Nombre del usuario | Identificación de la sesión activa                        |
| Ícono de salida    | Cierra la sesión                                          |

Sin sesión iniciada, el acceso a académicos lleva a la vista **pública** y aparece el botón **Ingresar**.

## Panel de Administración

Al entrar a **Administración** se muestra un menú lateral con las secciones de gestión:

| Sección                  | Para qué sirve                                   |
| ------------------------ | ------------------------------------------------ |
| **Configuración**        | Ajustes generales, categorías, opciones y cargos |
| **Líneas Investigación** | Asignar áreas de conocimiento a las líneas       |
| **Académicos**           | Crear, importar, editar y desvincular académicos |
| **Publicaciones**        | Revisar y ajustar el catálogo de publicaciones   |
| **Usuarios**             | Administrar las cuentas de acceso                |
| **Manual**               | Esta documentación                               |

El botón de menú (ícono de tres líneas) **colapsa** el panel para ganar espacio; vuelve a presionarlo para expandirlo.

## Configuración y sus pestañas

La sección **Configuración** se organiza en cuatro pestañas, visibles como submenú cuando estás dentro de ella:

- **General**: jornada completa equivalente y envío de códigos de edición.
- **Categorías**: categorías académicas por planta.
- **Opciones**: opciones válidas por categoría.
- **Cargos**: cargos laborales de los académicos.
